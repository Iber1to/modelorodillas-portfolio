# Roles de elaboración del README

| Rol | Responsabilidad | Puede aprobar versión final |
|---|---|---|
| Desarrollador | Exactitud técnica, código exportable, comandos y pruebas | No |
| Diseñador gráfico | Jerarquía visual, gráfico original y accesibilidad | No |
| Evaluador | Revisión de hechos, privacidad, licencias y coherencia con pruebas | **Sí, exclusivamente** |

Los roles son agentes de IA de esta sesión, no revisión clínica ni auditoría humana externa. La aprobación del Evaluador se conserva con el hash exacto del README en readme-review.json. Cualquier cambio posterior del README exige una nueva evaluación.
